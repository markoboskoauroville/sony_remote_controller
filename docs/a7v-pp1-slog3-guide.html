Sony A7 V: Picture Profile 1 for the most colour and dynamic range

Mantra Sony Remote · 28.10.2026 · menus as on the A7 IV generation; if a name differs on the A7 V, the place is the same

A Picture Profile stores only the look (gamma, colour space, colour settings). File format, bit depth, ISO and exposure live in other menus. Step 15 stores everything together on position 1 of the mode dial.

Part A: Picture Profile 1 (the look)

#WhereSet to
1MENU → Exposure/Color (purple tab) → Color/Tone → Picture Profile → highlight PP1, press rightopens PP1's settings
2PP1 → GammaS-Log3: the most dynamic range
3PP1 → Color ModeS-Gamut3.Cine: wide and easy to grade (S-Gamut3 for the very widest)
4PP1 → Black Level, Saturation, Color Phase, Color Depthall 0
5PP1 → Detail−7 (least in-camera sharpening)
6PP1 → Black Gamma, Kneeleave: S-Log3 switches them off
7Back on the Picture Profile list: PP1, middle buttonPP1 in use

Part B: the recording (not stored in PP1)

#WhereSet to
8MENU → Shooting (red tab) → Image Quality/Rec → File Format (movie)XAVC S-I 4K (best, large files) or XAVC HS 4K (H.265, smaller)
9Same group → Movie Settings → Record Settinga 10bit 4:2:2 option
10Same group → Rec Frame Ratethe project's rate, e.g. 25p
11Shutter (dial or MENU → Exposure/Color → Exposure)1/50 at 25p (twice the frame rate)
12MENU → Exposure/Color → Exposure → ISO800, manual (S-Log3's lowest)
13MENU → Exposure/Color → Zebra Display: On · Zebra Level: 94+expose +1 to +1.7 stops over the meter; brightest skin just starts to show zebra
14MENU → Setup (yellow) → Display Option → Gamma Disp. Assist: On · Gamma Disp. Assist Typ.: Autothe screen looks normal, the file stays log

Part C: store it all

#WhereSet to
15MENU → Shooting → Shooting Mode → Camera Set. Memory → 1 → OKPP1 + file format + ISO + zebra saved; mode dial to 1 recalls all

In DaVinci Resolve

Colour Space Transform: input S-Gamut3.Cine / S-Log3 → output Rec.709 / Gamma 2.4 (or through DaVinci Wide Gamut first), then grade.

ISO 800 and the +1 to +1.7 stops are general Sony S-Log3 practice, not yet measured on this A7 V. Sony's Camera Control PTP 3 lets a program set every value of Part A, the ISO, the zebra and the gamma assist over USB or the network (properties 0xD0E0–0xD0F5, 0xD23F, 0xD21E); the Mantra Sony Remote will do this by itself once the camera is connected.
