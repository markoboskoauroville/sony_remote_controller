# Sony Remote Controller

An Android remote for the Sony Alpha 7 V (and other current Alpha bodies) over
Wi-Fi: live view of the camera screen on the phone, plus photo, video,
exposure and focus-point control.

Two modes, switched in the app: **Sony Direct** (Wi-Fi to the camera, picture + control) and **Accsoon** (picture from the CineView Nano transmitter).

Status: planning. See [PLAN.md](PLAN.md) for the research, the decision, and
the step-by-step build and test plan.
